BELLAS KS - VERSION PROFESIONAL

Incluye:
- Panel de ingresos de hoy, semana y mes
- Gastos y ganancia mensual
- Registro de múltiples servicios por día
- Catálogo editable de servicios y precios
- Historial con filtros por fecha
- Reportes mensuales y semanales
- Servicios más realizados
- Editar y eliminar movimientos
- Exportar/importar respaldo JSON
- Logo Bellas KS e iconos para PWA

Para instalarla en iPhone:
1. La carpeta debe estar publicada en una URL HTTPS.
2. Abrir la URL en Safari.
3. Compartir -> Añadir a pantalla de inicio.

Nota: esta versión guarda los datos localmente en el dispositivo. Para compartir los mismos datos entre dos iPhone hay que conectar una base de datos en la nube.
